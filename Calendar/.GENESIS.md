# Calendar Genesis

## Purpose
The `Pleiades.Calendar` domain holds calendar logic that is specific to PLAINFRA chronology.

## Current Role
- Defines `PleiadeanCalendar`
- Converts to and from `DateTime`
- Encodes month lengths, leap-year behavior, and year-of-blood/sweat/tears labeling

## How It Works
- Uses a Persian-calendar-based epoch as the anchor point
- Counts day offsets from that epoch to derive Pleiadean dates
- Formats display strings for user-facing output in the console shell

## Why It Is Separate
This logic is cross-domain support. It is not orchestration, persistence, or identity; it is a calendar system used by the wider framework.
