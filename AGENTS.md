# TS/JS Files
- Do not end lines with ; inside TS/JS files (unless necessary).
- Use TABs for TS/JS files.

# Documentation
- There are multiple documentation files present in each subrepo (currently only in core), respect them and update them after each batch of changes if necessary:
  - `.ORIGIN.md`: Not to be updated by machine, contains the original proposal for the project.
  - `.DISCUSSION.md`: Records the concerns, unmet requirements and ambiguities in the project. Agents best keep this updated.
  - `.GENESIS.md`: In each domain, records the explanation and a brief on how it was created and how it works. Agents best keep this updated in each domain.
  - `.OPERATION-p*.md`: Keeps track of the backlog of a phase of operation.
  - `.DEVLOG-p*.md`: Oneshot report generated by agents on the progress of an operational phase.
- Keep XML documentation and its equivalents in other languages updated and descriptive.
- Try to avoid line comments, but actually do add them when required, like when some logic is not easily comprehended.
